# Reference implementations

Optional reading only. The Skill remains self-maintained; no external Skill is a runtime dependency.

- [Critical Thinking](https://github.com/tronghieu/agent-skills/blob/main/skills/critical-thinking/SKILL.md): distinguish missing evidence, inference failure, disagreement, and claims that cannot be assessed. Adopt the distinction, not its coaching workflow or report taxonomy.
- [Ground Truth](https://github.com/glichtenthal/ground-truth/blob/main/SKILL.md): calibrated agreement/disagreement; avoid forced criticism.
- [Anti-Sycophancy](https://github.com/mskadu/opencode-agent-skills/blob/main/skills/anti-sycophancy/SKILL.md): respond differently to repeated pressure versus substantive new evidence.

- [Using Agent Skills](https://github.com/addyosmani/agent-skills/blob/main/skills/using-agent-skills/SKILL.md): constructive pushback when an implementation approach has clear problems; explain the concern, offer an alternative and honor an informed override within allowed bounds.
- [UI Design Skill](https://github.com/nachiketkumar/ui-design-skill/blob/main/SKILL.md): one-time pushback on materially harmful requests, rather than repeated objections or critiques of minor preferences.

The concise decision discipline is an original synthesis, not copied source text.
