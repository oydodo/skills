# Codas Accept

Start with `codas-ontology`.

1. Identify the change and the person's actual decision on exactly it, and where it was made. Without
   an explicit decision, stop; silence, passing tests or a closed task are not decisions.
2. Follow the Note rules file for the Note's lifecycle. When a Note becomes implemented, the same
   change makes the current text it concerns say what now holds.
3. Do not merge before checks pass. Report the decision's source, the Note and any
   step not done and why.
