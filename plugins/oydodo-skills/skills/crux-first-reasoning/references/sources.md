# Conceptual references

This skill is an original, lightweight synthesis of general reasoning patterns. It does not copy any source skill verbatim. References are optional reading, not runtime dependencies.

- Anti-sycophancy: https://github.com/mskadu/opencode-agent-skills/blob/main/skills/anti-sycophancy/SKILL.md
- Ground Truth: https://github.com/glichtenthal/ground-truth/blob/main/SKILL.md
- First Principles Thinking: https://github.com/danyuchn/first-principles-skill/blob/main/SKILL.md
- Axiom: https://github.com/sickn33/agentic-awesome-skills/blob/main/skills/axiom/SKILL.md
- Good Strategy Bad Strategy: https://github.com/wondelai/skills/blob/main/good-strategy-bad-strategy/SKILL.md

- Thinking Toolkit (select one method; match depth to stakes): https://github.com/ponomr/thinking-toolkit/blob/main/SKILL.md
- Critical Thinking (distinguish unsupported claims, invalid inferences, value disagreements and unverifiable claims): https://github.com/tronghieu/agent-skills/blob/main/skills/critical-thinking/SKILL.md

Design differences: no forced disagreement; no claim that every problem has a single root cause; no mandatory long analysis template; prioritize decision-relevant evidence over stylistic brevity.
